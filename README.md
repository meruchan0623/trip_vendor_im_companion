# 旅游商家助手

在旅游商家桌面版的客服页面内提供出站翻译、草稿替换和 TSim_CS 订单查询。Windows 资源注入版安装一次后，从原客户端或原快捷方式启动，助手随客户端运行及完全退出。

## Windows 安装与启动

源码安装器版本为 **0.5.40**，宿主版本为 `0.3.2`。本版加入打开客户会话后约 10ms 自动滚到底部，并在最多 2 秒内补偿入站翻译引起的高度变化；主动上滚或消息列表交互会停止跟随。同步包含 TSIM 旧后端翻译兼容、按需订单工作台、页面性能及启动时序修复，详见 [Windows 0.5.40 更新说明](docs/2026-10-28-windows-injector-0.5.40.md)。

Windows 0.5.40 产物为 `release/旅游商家助手-0.5.40-Windows资源注入安装.exe`，构建及哈希见更新说明。本机历史安装验证版本为 **0.5.34**；新版构建不代表安装验收，发行文件不纳入 Git。

0.5.38 调整「套餐速览」：顶部新增业务流水号（EICCID）与 ICCID，均可复制；滚动条改为贴右边缘的细条；Windows 端改用 Microsoft YaHei UI / Cascadia Mono、文字加深、间距收紧并回调过大的字号；所有字段不再显示省略号：订单号保持单行完整显示，用量、CDR 地区等过长时换行。

0.5.37 新增「套餐速览」与启动最大化：打开带订单号的售后会话时，在「用户信息」下方显示只读套餐卡片（见日常使用）；客户端主窗口首次显示时默认最大化。构建门禁增加对应检查。

0.5.36 加强安装器的退出确认：结束进程后等待其真正退出，再连续 5 秒确认客户端、助手与更新程序没有重新启动，最多等待 60 秒；仍未稳定退出时停止注入，提示手动完全退出后重试。

0.5.35 源码补齐连接恢复和可见诊断：本机调试端点断流或持续无响应会在有界等待后失败并允许重试；Windows 原生辅助进程意外退出会按 1 / 3 / 10 秒退避重启，持续运行 60 秒后重置重试额度。加载、连接失败和助手退出时保留「… → 查看运行日志」，显示最近阶段、错误码和处理提示；正常翻译面板及关闭翻译时也保留日志入口。此说明不代表同事 Windows 机器已完成更新或验收。

0.5.34 改善 Windows 后台恢复：瞬时进程检查失败会有限重试，助手意外退出后会自动尝试恢复；多个账号页隐藏时保持等待，恢复前台后重新选择当前账号。原生助手启动减少一次 PowerShell 查询，并为启动身份校验保留充分的有界等待。售后订单可从已核验的当前会话提前识别，不必等待右侧详情内容显示；独立页面检查并行执行，打开查询时重新核对账号与会话。构建及模拟检查与真实客户端验收分别记录。

1. 先安装旅游商家桌面版。安装器支持 Windows x64、客户端 1.2.11 起满足结构兼容检查的版本；版本号满足要求仍需通过资源核验。
2. 打开安装器，选择实际客户端目录。默认目录、其他磁盘和当前用户安装目录均可选择。
3. 核对目标目录和本包版本，完全退出客户端后选择「我已手动退出，继续」。安装器提供手动退出、强制退出和取消，默认取消；受保护目录按提示提权。
4. 点击安装或更新注入。安装器保存原资源及安装收据，遇到中断先使用「恢复中断安装」。
5. 从原官方 EXE 或快捷方式启动，进入消息页并打开客户会话，等待翻译面板出现。

注入后客户端主窗口首次显示时默认最大化，Windows 与 macOS 共用此启动偏好；之后可自行还原或调整窗口，本次运行内不再干预。

关闭客户端窗口可能只是隐藏到后台；结束助手需要完全退出客户端。磁盘检测显示「注入完整」只表示文件状态，运行结果应在消息页确认。更新或卸载也必须先完全退出客户端，使用安装器操作，勿手工删除安装收据或原版备份。

## 登录与配置

**Windows：**先在本机默认数据目录中的 Edge 或 Chrome 普通配置登录 [TSim_CS](https://csagent.tsim.tech)。助手自动复用该配置的登录，不要求额外扩展。支持 `Default` 和 `Profile N`，不支持隐身或自定义数据目录。

面板提示未登录时点击「登录 TSim」，会先尝试恢复浏览器会话。更多菜单中的「打开浏览器 TSim_CS」打开已绑定配置；「断开助手会话」停止本次复用，不清除浏览器登录。需要更换浏览器配置时先断开，再重新连接。凭据不进入客服页面、面板状态和运行日志。

**macOS：**在助手面板点击「登录 TSim」，在助手应用内输入 TSIM 账号。会话由助手独立管理，不读取其他应用或浏览器的 Cookie，不需要完全磁盘访问权限。退出账号后清除助手保存的会话。

默认自动跟随客户原文语言。识别使用本地模型和当前会话的客户原文；无法确定或不支持时使用配置的兜底目标，并明确显示「兜底，非识别结果」。可在语言菜单手动选择目标或修改兜底语言。兜底设置保存在当前用户的 `translation-options.json`，保存失败会保留原设置并提示。

## 日常使用

- 输入中文后停笔约 500 毫秒生成译文预览。输入法组合期间不自动翻译；草稿、客户会话或账号变化会作废旧译文。
- 默认「Enter 直接发送」模式：普通 Enter 预约当前草稿，译文生成后替换、读回并发送。只有明确需要该行为时使用此模式。
- 「替换草稿」模式保留原客户端的 Enter 行为；面板替换按钮及 `Ctrl+Alt+Enter`（Mac 为 `⌘+⌥+Enter`）仅替换当前核验过的草稿。可撤销助手最近一次替换。
- 暂停翻译会停止自动请求；恢复后重新检查当前草稿。
- 点击识别到的订单号或手动输入标识查询订单。两端都在客服页面内打开 TSim 官方查询卡片，使用助手已登录的 TSim 账号，无需再次登录；助手未登录时先打开登录。换客户、账号失效或退出时关闭查询卡片。
- 打开带订单号的售后会话时，「用户信息」下方自动显示只读的「套餐速览」：环形仪表与大号数字显示剩余流量（≤20% 橙、用尽红、不限量 ∞），旁边是套餐状态、总用量与当日用量（如有）；渠道套餐名与源套餐名；供应商 / APN / eSIM 三格并排；业务流水号、ICCID、EID 每 4 位一组显示，复制按钮复制原始值，复制成功变为 ✓；设备型号；最近 10 条 CDR（今天的记录高亮，底色条表示相对用量，右上角为合计；同一地区时地区放在标题上；列表约 5 行高，鼠标停在列表内即可滚动，不显示 PLMN）。多个套餐按标签切换，最多读取 5 个，超出部分以「+N」提示。点击标题栏「套餐速览」或右上角箭头收起 / 展开，收起后仍显示状态、剩余量与套餐名；底栏显示「N 分钟前更新」。同一订单 60 秒内复用结果，3 秒内重复刷新不再请求。助手未登录、无订单查询权限或查询受限时，卡片显示对应提示。卡片不显示 IMSI、MSISDN 及 eSIM 安装凭据。Windows 上卡片使用 Microsoft YaHei UI 与 Cascadia Mono（Windows 10 回退 Consolas），文字 12–13.5px（剩余流量数字 20px）、近黑、间距紧凑；任何字段都不以省略号截断，过长内容自动换行；卡片与 CDR 列表的滚动条均为贴右边缘的 3px 细条。

## 排障

| 现象 | 处理 |
| --- | --- |
| 面板一直未出现 | 确认使用所选目录的原客户端入口，进入消息页并打开会话；查看运行日志的失败阶段 |
| 官方升级后助手失效 | 重新运行新版安装器核验并更新注入 |
| `WINDOWS_MANIFEST_NOT_PROTECTED` | 客户端目录或其祖先可被其他普通用户替换；调整安装位置，勿修改整个 AppData 的系统权限 |
| 翻译提示登录 | 在已绑定的 Edge/Chrome 配置重新登录，或断开后重连 |
| 显示兜底语言 | 客户原文不足以确认语言；可继续使用兜底或手动选择目标 |
| 订单查询打不开 | 确认助手面板已登录 TSim 且账号有订单查询权限；查询卡片提示登录时按卡片内提示处理 |
| 套餐速览未显示或提示失败 | 确认消息页在前台、当前会话带有订单号且助手已登录 TSim；提示查询频繁时稍后点「重试」 |
| 安装中断 | 使用安装器的恢复功能，不用旧备份覆盖已经升级的官方程序 |

点击助手「… → 查看运行日志」可查看、刷新及复制最近记录，即使助手面板尚未挂载或助手进程已退出，Windows 启动入口仍能展示本次保留的日志。各运行时日志缓存最多 1000 条，超过后淘汰最早记录；重新启动后内存日志重新累计。磁盘日志位于 `%APPDATA%/trip_vendor_im_companion/logs/runtime.log`，仅保留当前与上一份日志，各最多 500 条且各不超过 512 KiB，两份合计最多 1000 条。只记录白名单阶段、耗时及固定错误码，不记录客户正文、译文或凭据。

出站翻译请求在助手独立会话、浏览器桥与兼容读取链路的 HTTP 出口统一使用六字段白名单：`text`、`target_lang`、`source_lang`、`purpose`、`draft_request_id`、`composer_content_version`。为兼容拒绝额外字段的旧 TSIM 后端，默认不发送可选的 `client_source`，不需要先升级后端；服务端插件来源细分统计暂不能通过该字段归属。本地诊断仍可用，422 不会触发删字段重试或重复翻译。请求格式校验、权限、限流、超时与连接错误分别提示。

翻译日志提供中文摘要与原始字段切换：输入等待、会话复核、HTTP 响应头/响应体/解析、编辑器核对和预览确认耗时，记录取消、过期结果及发送待确认；另有运行环境、30 秒健康采样和 5 分钟汇总。可额外接收配套 TSIM 后端返回的输入/输出及缓存 Token、上游调用/排队耗时、TSIM 处理耗时与结果来源；只统计本请求新建调用，不复制缓存或共享在途请求的历史用量。未提供诊断的后端仍显示未知，不影响翻译。字段口径和容量见 [翻译运行日志](docs/translation-runtime-diagnostics.md)。

启动检查复用隐藏 PowerShell 进程，系统查询代码只编译一次，以 Win32 进程接口读取身份；每次连接仍核对用户、进程创建时间、监听器、客户端版本及资源。已有本机只读测量中检查链由约 22.4 秒降至 4.2–4.4 秒；完整原入口冷启动低于 10 秒仍待验证。

## 开发与构建

需要 Node.js/npm。Windows 原生组件需要 .NET 10 SDK；Windows 安装器打包脚本优先使用 `work/tools/dotnet/dotnet.exe`，也可通过 `TMC_DOTNET` 指定 SDK。

```powershell
npm ci
npm run typecheck
npm run build
npm run package:windows:injector
```

安装器构建会生成前端、Electron 载荷、原生窗口助手及安装 EXE，打包前先运行订单窗口检查 `node tests/run-operator-overlay.mjs`（与 macOS 共用的查询页交接及复用逻辑，不依赖平台）、套餐速览检查 `node tests/run-order-summary.mjs` 与启动最大化检查 `node tests/run-vendor-window-defaults.mjs`。`npm start` 是保留的独立开发入口，Windows 资源注入版日常使用原客户端入口。

`TMC_RUNTIME_PLATFORM=win32|darwin` 控制运行时构建平台。`TMC_WINDOWS_DYNAMIC=1` 由注入安装器打包启用，运行时清单由安装现场生成，不接受外部构建清单替代。

保留的轻量 Windows 宿主通过 `npm run package:lightweight` 构建，细节见 [轻量宿主](native/resident/README.md)。浏览器扩展桥是可选兼容实现，不属于默认登录链路。

### macOS 一次性注入安装器

0.7.4 候选版合入翻译旧协议兼容、TSIM 错误提示及页面性能修复：订单工作台仅点击时加载，关闭后最多保留 60 秒；稳定心跳不重复刷新摘要，订单观察和语言识别按相关变化更新。已生成 `release/旅游商家助手-0.7.4-macOS一次性注入安装器-arm64.zip`，完整打包流程 191 项 TAP 测试及隔离安装事务、官方样本检查通过；未安装到用户客户端。官方页面自身的秒级长任务及旧 Electron 运行时仍需实机复测，不能据此宣称全部卡顿已解决。见 [修复计划](docs/2026-10-28-tsim-client-performance-and-translation-fix-plan.md) 和 [验收记录、校验和与限制](docs/2026-10-28-tsim-injector-0.7.4-validation.md)。

用户自行重装官方客户端以清除旧的客户端修改。Codex 后续只修改本仓库并生成安装器，不直接操作已安装客户端组件。旧的 IM 启动节流和 BrowserView 重挂载修补已移除，仅保留助手入口集成。

需要 Apple Silicon 构建主机及受支持的官方原件（当前为 1.2.12 / ares 1.2.15）。运行时支持已核验的内置页面及当前用户目录中的 1.2.15 / 1.2.16 页面，未知版本或文件变化会停止连接：

```sh
node scripts/inject-macos-official.mjs --official work/mac-arm64/official-apple.dmg
npm run package:mac:injector -- --official work/mac-arm64/official-apple.dmg --version 0.7.4
```

构建仅写入工作目录及发行目录。打开生成的一次性安装器，核对 `/Applications/旅游商家桌面版.app`，完全退出客户端后手动安装；之后从原客户端入口启动。更新及卸载也由用户在安装器内操作。安装器核验目标、保留原版备份，拒绝用旧备份覆盖已被官方升级或改动的客户端。原命令的 `--install` / `--install-built` 直接安装入口已停用。

macOS 登录使用助手自己的受保护会话。Windows 的浏览器登录方式保留。Mac 助手仅打包中文简体、中文繁体和英文 Electron 界面资源，客户语言识别与翻译目标语言不受影响。

后台恢复与订单提速的共有能力已同步到 macOS：提前读取已核验的当前会话订单、并行执行独立检查、查询前重新核对会话，以及原生助手迟到就绪后的恢复。Mac 独立启动器补齐助手异常退出后的有限重试；保持助手自有登录，不修改官方窗口、BrowserView 或渲染节流。「套餐速览」与启动最大化两端共用：macOS 由助手自有会话查询；最大化是用户要求的入口启动偏好，只在官方主窗口首次显示时执行一次，不改变窗口的显示、隐藏、关闭或 BrowserView 挂载。两端源码与验证范围见 [跨平台同步记录](docs/windows-macos-parity.md)。

Mac 载荷和安装器构建入口会先运行真实 Electron 窗口最大化回归（隔离窗口，不加载官方业务代码）、页面选择、独立登录、订单识别、原生助手、查询浮层、套餐速览、启动最大化与隔离启动器恢复检查。Shell 构建脚本通过 `.gitattributes` 固定 LF 行尾，避免 Windows 检出后在 Mac 上无法执行。

隔离登录与订单检查：`node tests/run-macos-owned-session.mjs`；页面内订单窗口检查：`node tests/run-operator-overlay.mjs`。原生安装事务检查见 [macOS 安装器说明](native/macos-installer/README.md)。构建成功不代表物理键盘、输入法、原客户端冷启动或真实服务验收。
