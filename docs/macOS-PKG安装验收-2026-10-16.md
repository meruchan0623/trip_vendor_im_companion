## 构建与清理

```bash
npm run clean:mac
npm run package:mac -- --official-app '/path/to/旅游商家桌面版.app'
```

构建输入必须为未修改的受支持官方原包，不能传入旧版集成发行程序。`package:mac:pkg` 与 `package:mac` 相同。独立助手的开发构建入口保留为 `package:mac:app`。

`clean:mac` 删除生成的发行包及编译输出，不修改 `/Applications` 中的程序或系统中的回退备份；官方源安装包必须放在被清理的构建目录之外。本轮还清除了旧 ARM 迁移临时副本、下载碎片、解包目录与原生编译中间目录，保留官方 DMG、核验过的下载输入和既有验收记录。
