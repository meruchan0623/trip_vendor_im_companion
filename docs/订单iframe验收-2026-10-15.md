# 0.3.2 订单 iframe 修正与验收

2026-10-15：订单入口改为在原商家客服页面中显示 TSim_CS `/embed/operator` 原网页。此前的字段查询和结果投影不再用于生产页面。

## 当前行为

- 点击订单快捷按钮，以 `order_number` 类型打开 iframe；手动提交标识时由 TSim_CS 判别类型。订单 ID 按字符串传递，保留前导零。
- iframe URL 携带 `identifier`、可选 `identifierType` 和每次打开的新 `requestId`，无需父子页面握手后才显示。
- 网页负责登录、加载、查询与结果展示；宿主始终保留关闭按钮，辅助超时和失败提示不会隐藏网页。iframe `load` 不代表业务查询成功。
- 关闭、切换会话、页面隐藏、退出或租约结束时移除 iframe。消息校验来源窗口、域名及对应请求；旧 frame 不能关闭新查询。
- 嵌入页面的 `queryOrder` intent 已移除，后台不再向 renderer 发布订单字段。历史服务方法暂留，但当前生产页面不调用它。
- 翻译仍使用原流程；iframe 使用商家客户端自己的会话，与 Chrome / Edge 中用于翻译的会话独立。

## 尚未验证

没有在真实商家客户端中完成 iframe 登录、登录后订单内容、跨账号登录隔离、真实输入法与长时间运行验收。隔离 Electron 的内核与商家客户端内核不同，可嵌入性验证不能替代商家客户端验收。没有修改厂商程序文件、生产 TSim_CS 代码，也没有发送客户消息。

旧 0.3.1 的字段查询成功记录不适用于本次 iframe 方案。

## 使用

从托盘退出旧版助手后，启动 `release/TravelMerchantCompanion-0.3.2-win-x64.exe`。点击订单按钮，在出现的 TSim_CS iframe 中按需登录，再查看原网页的订单内容。使用说明见 `release/TravelMerchantCompanion-0.3.2-使用说明.txt`。
