| TSIM 术语 | 面板、独立登录、订单工作台、摘要及格式化日志统一 TSIM；历史内部错误码、账号作用域和存储键保持兼容，原始诊断仍保留原值 |
| 工作台加载 | 取消自动完整 SPA 与连接预热，仅点击加载；关闭后最多保留 60 秒，重新打开核对期限与授权；会话/账号变化、失效、pagehide、dispose 释放 |
| 订单观察 | 单轮祖先可见性及来源节点缓存，相关变动合并处理；导航、来源变化、候选歧义仍拒绝旧订单；host hint 撤回时恢复最新合法 DOM 来源 |
| 摘要布局 | 相同数据与稳定心跳不再重排；几何读写分离、只写变化样式、过滤无关滚动；官方弹窗及子页追加内容分别触发布局/层级失效 |
| 语言识别 | 当前会话最多 30 条原文窗口的单项缓存，签名上限 64 KiB；文本、归属、可见性变化仍重新采集，原文不变不重复推理 |
| 长文本清理 | 处理邮件、域名及数字 token 清理中的重复回溯；新增 7 万字符无空格、异常邮箱和点分隔文本的完整检测回归 |
| 输入安全 | 保留 native 双快照、中文 IME、租约、安全读回及发送前校验；未根据低占比采样重写输入链，也未修改官方窗口或渲染机制 |
| 安装事务 | 新增真实 Swift Engine / InjectionBuilder 的隔离集成测试，纳入统一打包检查 |

兼容旧后端的代价：不再通过 `client_source` 为服务端新增插件来源细分统计；这不改变翻译鉴权、预算或草稿契约。后端升级不是使用本包恢复兼容请求的前置条件。

DOM 模拟与合成文本测试证明行为边界及特定重复计算已被处理，不证明真实客户端的毫秒级指标已达成。官方页面的秒级长任务、未归因原生工作、旧 x64 运行时及系统内存压力仍是剩余风险；本包未替换官方 Electron，也未屏蔽官方脚本。
