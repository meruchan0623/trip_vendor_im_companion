# Windows 注入包 0.5.40

本版本基于 `bd9fddf` 同步后的源码，加入打开客户会话后的消息滚动补偿。Windows 宿主基础版本仍为 0.3.2，注入器版本为 0.5.40。

## 会话滚动

已核验的客户会话打开后，约 10ms 执行首次滚到底部。在随后最多 2 秒内，每 50ms 检查消息区域尺寸；仅尺寸发生变化时再次滚到底部，以补偿官方入站翻译或延迟渲染带来的高度变化。定时器调度和渲染负载可能延后首次执行，10ms 不是屏幕呈现时延保证。

只操作 `.chat_list_content` 对应的可滚动消息容器。用户主动向上阅读或在消息列表交互后停止补偿；会话切换、页面隐藏、绑定失效和销毁会取消旧任务。稳定的宿主心跳不重复开启滚动窗口。2 秒窗口结束后不持续抢占用户滚动位置，超过该窗口才返回的翻译仍需真实环境观察。

## Windows 更新特别说明

- 本包承接 [0.5.39 共享修复](2026-10-28-windows-injector-0.5.39-build-handoff.md)：首次翻译请求使用旧后端兼容的六字段，不发送 `client_source`，不要求后端先支持来源字段，也不在 422 后删字段重试。
- 安装前保存工作并完全退出官方客户端、助手与更新程序。安装器强制退出流程最多等待 60 秒，并连续确认 5 秒没有相关进程重启。
- 使用新版安装器选择实际客户端目录并更新；安装中断使用恢复功能，不手工删除收据或用旧备份覆盖升级后的官方资源。
- Windows 保留 Edge/Chrome 普通配置登录方式。安装完成后从原官方入口启动。

## 验证与交付

构建入口为 `npm run package:windows:injector`，加入会话滚动回归门禁，其余 Windows 生命周期、翻译、订单、性能、原生绑定及安装器退出检查继续执行。

产物为 `release/旅游商家助手-0.5.40-Windows资源注入安装.exe`、同名 SHA-256 文件及 `release/旅游商家助手-0.5.40-Windows更新特别说明.txt`；构建报告位于 `work/windows-inject/build-report.json`。

本次不自动安装，不发送客户消息。真实客户端应验收：首次打开会话、翻译延迟出现、快速切换会话、向上阅读历史消息、窗口缩放及长时间运行；自动化模拟不能替代这些验收。

构建结果：Windows 完整打包门禁通过，会话滚动回归 win32 / darwin 各 15/15，既有页面性能检查 6/6；原生绑定 45 项与安装器退出检查通过。EXE 版本、SHA-256 及 Brotli 载荷解压哈希读回通过。EXE 大小为 230684835 字节，SHA-256：`414beaba82fca2fe59487d4c6910da5034ecfda4f2ada13eb94becb74ba269e2`。构建包含会话滚动提交 `e1642fc`；本次未安装或进行真实客户端验收。
