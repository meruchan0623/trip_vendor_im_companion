# 2026-10-14 窗口外挂重做

用户改为窗口跟随、文本框替换、订单点击覆盖层和系统无边框浏览器浮层。此前的内嵌远程视图、原页面内挂载 UI 路线不再用于默认程序。

## 当前调用链

`electron/main.ts` 创建连接设置窗、原输入区翻译工具条、订单浮层关闭按钮及最多 12 个文字范围小窗。主功能在原客户端消息页内部显示；设置窗仅用于连接配置。`native/windows` 跟踪已核验原 EXE 的 HWND，发出物理坐标、客户区坐标、可见性、最小化、DPI 和窗口组前台状态。Electron 将物理坐标转换为显示器 DIP，不以焦点变化强行激活目标。

`electron/companion-service.ts` 持有认证与翻译状态，出站原文直接从原文本框读取。`electron/external-composer.ts` 核验进程、安装指纹、loopback listener、已载入的页面/renderer 指纹后使用编辑器公共 API。该连接不挂载旧 runtime UI，也不创建页面 iframe。后台只更新租约，不读取客户正文。旧 runtime 的发送方法未暴露给新的 standalone API。

订单标识来自右侧已核验订单 iframe 的订单 ID 行及可见原聊天文字 Range；只读扫描生成坐标。每个标识占用独立小窗，其他区域仍由原客户端接收点击。重新查询前核验所点文字、位置和当前客户，避免滚动、切会话后使用旧入口。

`electron/system-browser.ts` 以专用 profile 启动已安装系统 Edge 的 `--app` 窗口；native 通过进程及 profile 参数核验窗口后去边框、移动、隐藏和关闭。查询 URL 使用原 operator direct-load 契约，带 identifier、identifierType、requestId 和 source。既有窗口与凭据不被收养或复制。
